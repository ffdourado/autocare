# AutoCare – Sistema de Gestão e Manutenção Preventiva de Veículos

## 1. Introdução
O AutoCare é um sistema simples criado como parte de um projeto acadêmico da UNINOVE, com o objetivo de facilitar o controle e a manutenção preventiva de veículos, ajudando o usuário a saber quando realizar serviços essenciais como troca de óleo, alinhamento, balanceamento e inspeções gerais.

## 2. Objetivo Geral
Criar um sistema básico que registre veículos e forneça informações simuladas sobre manutenções preventivas recomendadas.

## 3. Objetivos Específicos
- Cadastrar veículos
- Listar veículos cadastrados
- Exibir alertas de manutenção simulados
- Organizar dados de forma simples e acessível

## 4. Justificativa
A maior parte dos motoristas não acompanha corretamente a manutenção do seu veículo. Com isso, acabam gastando mais dinheiro do que deveriam ao longo do tempo. O AutoCare resolve esse problema com um sistema simples e eficaz.

## 5. Tecnologias Utilizadas
- Python
- Flask (framework web simples)

## 6. Rotas da API
- GET `/`

- POST `/veiculos`
